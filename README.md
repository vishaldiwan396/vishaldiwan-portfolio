# vishaldiwan.runs-on.dev

Portfolio site. Vite + React frame — no content yet.

## Dev

```
npm install
npm run dev
```

## Deploy

Pushing to `main` builds and publishes to GitHub Pages via
`.github/workflows/deploy.yml`. The custom domain (`public/CNAME`) is
`vishaldiwan.runs-on.dev`.

GitHub repo settings → Pages → Source must be set to "GitHub Actions" for
the workflow to publish correctly.
